# ファームウェアリポジトリ

基板 1 枚で動くファームウェアのリポジトリです。基板名に `_fw` を付けた名前にします（例: `gamma_turret_fw`）。
市販ボードで動かすものは `製品名_役割_fw` にします。既存のリポジトリは既存名のままです。

## 置くもの

| 内容 | 置き場 |
|---|---|
| ファームウェアのプロジェクト一式 | ルート |
| 共通ライブラリ | git submodule |
| 設計判断の記録 | `docs/` |

## 構成

- ビルドシステムや開発環境は基板ごとに選びます。環境構築からビルド、書き込みまでの手順を README に書きます
- 共通ライブラリは git submodule で参照し、コミットを固定します（[common-lib.md](./common-lib.md)）
- 使用機体は書きません。機体管理リポジトリ側からリンクします
